[Notion API 개인 액세스 토큰 발급 방법]

1. Notion에 로그인한다. 구글계정으로 회원 가입
   https://app.notion.com/ko

2. 개발자 도구로 이동한다. https://app.notion.com/developers
   현재 Notion 화면에서 상단에
   [시작하기] [Worker] [연결] [개인 액세스 토큰]   메뉴가 표시된다.

3. [개인 액세스 토큰]을 클릭한다.

4. 새 개인 액세스 토큰을 생성한다.

5. 발급된 토큰을 복사하여 안전하게 보관한다.
   토큰 예시:   ntn_xxxxxxxxxxxxxxxxxxxxxxxxx

6. Python, LangChain, n8n 등에서 Notion API를 사용할 때
   발급받은 토큰을 API 인증 정보로 사용한다.

주의사항
- API 토큰은 비밀번호와 같이 안전하게 관리한다.
- GitHub나 공개 문서에 실제 토큰을 입력하지 않는다.
- 토큰이 외부에 노출되면 폐기하고 새 토큰을 발급한다.

[API 토큰과 회의록 DB 연결하는 방법]

1. Notion  홈페이지 접속 : https://app.notion.com/ko
우측 상단의  <Notion 열기> 버튼 클릭

2. 안녕하세요 가 보이는 창에서  좌측 메뉴의 새페이지 추가 메뉴 클릭

3. 빈데이터베이스 클릭

4. 상단의 새 데이터베이스에 "회의록"으로 이름 변경

5. Notion 개발자 홈피 접속 : https://app.notion.com/developers

6. 상단의 개발자 도구에서 "연결" 클릭  --> 우측의 "+신규 연결" 버튼 클릭

7. 신규 연결 창에서 연결이름을 "n8n-agent"로 입력해주고 그대로 하단의
   "연결 생성하기" 버튼 클릭 (인증방법은 액세스 토큰으로 그대로 둔다)

8. Notion 홈페이지에서 위에 만든 회의록으로 가서 우측 상단의 "..." 을 클릭하고
   "연결" 메뉴를 선택하고 스크롤하면 "n8n-agent"가 보이는데 클릭한다
    이 페이지에 n8n-agent 추가 창이 뜨면 "페이지에 추가 버튼"을 클릭한다
